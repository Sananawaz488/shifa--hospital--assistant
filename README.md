# 🏥 Shifa — Hospital Policy Assistant

An AI-powered chatbot that answers questions about hospital policies using Retrieval-Augmented Generation (RAG). It searches through hospital policy documents and generates accurate, grounded answers — with source citations for every response.

## ✨ Features

- 💬 Simple chat interface built with Streamlit
- 🔍 Semantic search over hospital policy PDFs using FAISS
- 🤖 Answers generated by Groq's `openai/gpt-oss-120b` model
- 📄 Every answer shows which document(s) it came from
- 🔒 API key stored securely via Streamlit secrets (never exposed in the UI)

## 🧠 How It Works

1. **Ingestion** (`ingest.py`, run in Google Colab)
   - Reads hospital policy PDFs
   - Splits them into overlapping text chunks
   - Converts chunks into embeddings using `sentence-transformers`
   - Saves everything into a local FAISS vector index

2. **Retrieval + Generation** (`app.py`)
   - User asks a question in the chat UI
   - The app searches the FAISS index for the most relevant chunks
   - Those chunks are sent as context to the Groq LLM
   - The model generates an answer grounded in the retrieved policy text
   - Source document names are shown alongside the answer
